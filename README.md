# 理象八字

免费、开源（MIT）的八字排盘与学习工具。主打一件事：**让用的人越用越会看盘**，而不是越用越依赖软件。

- **断盘**：纯规则自动推演，给出总论（如“乾造，甲木日主，生于卯月，阳刃格……”）和喜忌，分性格、财富、事业官运、婚姻感情、子女、六亲、健康养生逐项断语，每步大运、每个流年都有分析；每条断语附推断依据，可一键复制全文
- **理法**：干支关系 → 旺衰（得令/得地/得势 + 公开的量化模型）→ 格局（子平取格 + 成败自检）→ 用神（扶抑 + 调候）
- **象法**：日柱象、宫位 × 十神、十神组合象（带成象条件）、干支类象、常用神煞
- **学堂**：基础知识 → 初级 → 中级（理法）→ 高级（象法与实战）→ 研修，共 21 课，每课配练习，按通过率解锁
- **练习场**：十神识别、地支藏干、五虎/五鼠遁、地支关系、旺衰判断，随机出题无限刷
- **先断后验**：可遮住自动分析，先写自己的判断，再对照、记录分歧
- **隐私**：纯前端，无服务器、无账号，命例只存在浏览器本地，可导出 JSON

## 开发

```bash
pnpm install
pnpm dev        # 本地开发 http://localhost:5173
pnpm test       # 核心引擎单元测试（Node 原生 test runner）
pnpm build      # 产物在 dist/，纯静态，可部署到 Cloudflare Pages / GitHub Pages / NAS
```

## 已知简化（欢迎 PR）

- 旺衰模型为静态计数，未计算合化、冲克对力量的增减，未分透干与否；结论中会主动提示
- 用神只自动给出扶抑与调候，通关、病药、从格/专旺需人工判断
- 断盘为书本规则推演，相当于“初步结论”；疾病、寿命、灾祸类只作中性提示，不作断定
- 神煞只收录最常用的十余种
- 阴干长生采用传统顺逆说，旺衰计算不依赖它
